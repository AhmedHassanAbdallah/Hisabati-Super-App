# حساباتي HVAC — HESABATI HVAC

**AIR CONDITIONING & REFRIGERATION MANAGEMENT**

تطبيق متكامل لإدارة ومحاسبة أعمال التكييف والتبريد والصيانة والتركيب والإصلاح — إصدار متخصص ومستقل من عائلة تطبيقات «حساباتي»، بنفس نظام التصميم.

© 2026 أحمد حسن عبدالله — جميع الحقوق محفوظة.

## الاستقلال عن تطبيقات حساباتي الأخرى

## الأقسام

- **الفواتير والمستندات:** تركيب، صيانة، إصلاح، قطع غيار، ختامية، مقايسة، عرض سعر (يتحول لفاتورة).
- **طرق المحاسبة لكل بند:** بالجهاز، بالزيارة، بالعملية، بالوحدة، بالمتر الطولي (× عدد الخطوط)، بالقطعة، بالوزن (كجم/جرام)، باليومية (× عدد الفنيين)، بالساعة، مقاولة، مراحل تنفيذ.
- **فصل الحسابات:** الخدمات، الكشف، الأجهزة، قطع الغيار، الخامات، الفريون، الأجور، النقل — وتوريد الفني أو خامات العميل.
- **المدفوعات:** عربون ودفعات متعددة بطرق دفع مختلفة، إيصال لكل دفعة.
- **العملاء والأجهزة:** عدد غير محدود من الأجهزة لكل عميل، وسجل صيانة كامل لكل جهاز.
- **الزيارات والتقارير الفنية:** المشكلة، العطل، السبب، الأعمال، القطع (تتخصم من المخزن)، الفريون، القراءات، صور قبل/بعد، الضمان، الموعد القادم.
- **المخزن:** 20 تصنيف للخامات وقطع الغيار، سعر شراء وبيع وهامش ربح، حركة الصنف، حد أدنى للتنبيه.
- **الفنيين:** اليومية، الإضافي، السلف، الخصومات، الصرف، المستحق.
- **الحسابات:** الإيرادات المحصلة، المصروفات، صافي الربح = المحصل − التكاليف المدفوعة.
- **قوائم الأسعار، عقود الصيانة، الضمان والمواعيد (تصدير للتقويم)، النوتة الفنية، الحاسبات، كشوفات الخامات.**
- **PDF:** نفس نظام الطباعة الأصلي (A4 قابل للتعديل، متعدد الصفحات، عربي RTL).
- **العملات:** كل العملات العربية بنفس نظام حساباتي (الرمز والكسور فقط، بدون تحويل المبالغ) + أسعار صرف مرجعية منفصلة.

## الملفات

```
index.html          الواجهة + CSS الأصلي لحساباتي بدون تغيير + إضافات HVAC
js/core.js          التخزين المستقل، العملات، المظهر، النوافذ والصفحات
js/catalog.js       تصنيفات الأعمال، طرق الحساب، الأجهزة، الفريون
js/docs.js          محرك المحاسبة والفواتير والمدفوعات
js/customers.js     العملاء والأجهزة والزيارات
js/modules.js       المخزن، الفنيين، الحسابات، الأسعار، العقود، الضمان، النوتة
js/calc.js          الحاسبات
js/print.js         المستندات PDF ونصوص واتساب
js/app.js           الصور، النسخ الاحتياطي، التحديثات، التشغيل
service-worker.js   العمل بدون إنترنت + اختيار الإصدار
tests/run-tests.js  الاختبارات
```

## الاختبار

