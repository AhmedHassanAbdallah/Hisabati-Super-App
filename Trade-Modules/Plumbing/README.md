# حساباتي السباكة — HESABATI PLUMBING

**PROFESSIONAL PLUMBING & SANITARY WORK ACCOUNTING SYSTEM**

نظام متكامل لإدارة ومحاسبة أعمال السباكة والصحي وشبكات المياه والصرف: التأسيس والتشطيب والصيانة، الخامات والأدوات الصحية، العمال والمصروفات والدفعات، والمقايسات والفواتير الاحترافية PDF — إصدار متخصص ومستقل من عائلة تطبيقات «حساباتي» بنفس نظام التصميم.

## طرق المحاسبة (لكل بند)

| الطريقة | المعادلة |
|---|---|
| بالنقطة | عدد النقاط × سعر النقطة |
| بالحمام / بالمطبخ | العدد × السعر، أو تسعير كل مرحلة (تغذية، صرف، تشطيب، تركيب، اختبار) |
| بالمتر الطولي | الطول × عدد الخطوط × سعر المتر (نوع الماسورة، القطر، الضغط) |
| بالقطعة | العدد × سعر القطعة |
| توريد وتركيب | العدد × (سعر البيع + مصنعية التركيب) — وسعر الشراء منفصل للربح |
| باليومية | اليومية × الأيام × عدد العمال + الإضافي − السلف − الخصومات |
| بالساعة / بالعملية / بالزيارة | العدد × السعر (رسوم الزيارة منفصلة عن الإصلاح وقطع الغيار) |
| بالمتر المكعب | الطول × العرض × العمق × سعر المتر المكعب |
| مقاولة | مبلغ إجمالي + نطاق العمل والمشمول وغير المشمول والتواريخ والشروط |
| مراحل العمل | 13 مرحلة قابلة للتعديل، لكل مرحلة سعر وكمية وملاحظات وحالة تنفيذ |
| عقود الصيانة | شهري / ربع سنوي / نصف سنوي / سنوي بعدد الزيارات والخدمات |

### تعريف النقطة ومنع التكرار

- **تعريف النقطة قابل للتغيير** (المزيد ← تعريف النقاط): «نقطة الجهاز شاملة التغذية والصرف» أو «كل توصيلة لوحدها»، وأنواع النقاط نفسها تتضاف وتتعدل وتتحذف.
- التطبيق **ينبه ويطلب موافقة صريحة** قبل حفظ بند يكرر الحساب: نفس البند في نفس المكان، توصيلة منفردة لجهاز محسوب بنقطة شاملة، حمام متسعر بالكامل ومعاه نقاط، أو سعر شامل الخامات مع خامات متسعرة لوحدها.
- **الخامات تتحسب مرة واحدة** في الربح: الأكبر من (تكلفة الشراء في البنود) و(مصروفات الخامات المسجلة على نفس المستند/المشروع).
- **المصنعية لا تتخلط بالخامات**: مصنعية تركيب بنود التوريد بتتجمع على «المصنعية» وثمن التوريد على نوعه (مواسير / وصلات / أدوات صحية / معدات / قطع غيار).

## الأقسام

- **المستندات (PDF عربي RTL):** مقايسة تأسيس، مقايسة تشطيب، مقايسة شبكة تغذية، مقايسة شبكة صرف، مقايسة حمام، مقايسة مطبخ، عرض سعر، فاتورة أعمال، فاتورة توريد وتركيب، فاتورة صيانة، فاتورة ختامية، إيصال استلام دفعة، كشف حساب عميل، تقرير مصروفات المشروع، تقرير صيانة وإصلاح، عقد صيانة، كشف خامات.
- **الحاسبات:** النقاط، الحمام، المطبخ، المواسير والشبكات (هالك اختياري + طول العود عند المورد + وصلات بحصر يدوي)، القطع والأدوات الصحية، الطلمبات والخزانات (مرجع السعة مرجعي فقط)، الحفر، اليومية، الصيانة، تحويل العملات المرجعي.
- **العملاء والمشروعات:** العميل له أي عدد من المشروعات؛ كل مشروع يجمع مقايساته وفواتيره وحصره (نقاط، مواسير، وصلات، أدوات) ومصروفاته وأجور عماله وزياراته وملاحظاته وربحه.
- **سجل الصيانة:** تاريخ الزيارة، نوع المشكلة، وصف ومكان العطل، نوع الإصلاح، القطع المستبدلة والخامات، أجرة الزيارة، مصنعية الإصلاح، الضمان، صور قبل/بعد، وبحث في السجل.
- **الخامات والأدوات الصحية:** مواسير (PPR/PVC/UPVC/CPVC/PEX/HDPE/نحاس/مجلفن)، قطع ووصلات، أدوات صحية، معدات — شركة، موديل، مقاس، وحدة، شراء/بيع، مورد، هامش ربح، حركة الصنف، خصم تلقائي في الفواتير والزيارات، وخامات السباك أو العميل.
- **العمال والفريق:** اليومية، الإضافي، السلف، الخصومات، المهام، المستحقات، وتعدد العمال في المشروع.
- **الحسابات:** صافي الربح = الإيرادات المحصلة − التكاليف الفعلية المدفوعة؛ عربون ودفعات متعددة بطرق دفع مختلفة.
- **قوائم الأسعار:** قوائم متعددة، نسخ واستنساخ، بدون أي سعر إجباري.
- **النوتة:** مقاسات المواسير، مواقع المحابس، المسارات، الخزانات والطلمبات، الاتفاقات، المواعيد — مربوطة بالعملاء والمشروعات.
- **العملات:** 22 عملة عربية + الدولار بنفس نظام حساباتي (الرمز والكسور فقط، بدون تحويل المبالغ).
- **بدون إنترنت:** تخزين محلي، نسخة احتياطية JSON كاملة (بالصور والإعدادات) واستعادة، وService Worker.

js/catalog.js       تصنيفات الأعمال، طرق الحساب، تعريف النقطة، تنظيف البيانات
js/docs.js          محرك المحاسبة والمستندات، منع التكرار، المدفوعات
js/customers.js     العملاء والمشروعات وسجل الصيانة
js/modules.js       المخزن، العمال، الحسابات، الأسعار، العقود، المواعيد، النوتة
