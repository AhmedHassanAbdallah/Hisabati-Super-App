# حساباتي نقاشة — HESABATI PAINTING

نظام متكامل لإدارة أعمال النقاشة والدهانات: حساب مساحات الحوائط والأسقف، إدارة المقاولات والعملاء والخامات والعمال والمصروفات، وإنشاء المقايسات والفواتير الاحترافية PDF.

تطبيق ويب تقدمي (PWA) في ملف واحد `index.html`، يعمل بدون إنترنت، ويتغلف كتطبيق أندرويد (APK) من مجلد `android/`.

## مستقل تماماً عن «حساباتي» للكهرباء

المشروع ده نسخة مستقلة مبنية على «حساباتي» 2.4.0 (مستودع Ezaza)، بنفس التصميم وتجربة الاستخدام، لكن:

| | حساباتي (كهرباء) | حساباتي نقاشة |
|---|---|---|
| المستودع | `Ezaza` | `Hesabaty-painting` |
| مفاتيح التخزين المحلي | `ahmed_elec_invoices_v7`، `hesabaty_*` | `hpaint_projects_v1`، `hpaint_*` |
| كاش الـ Service Worker | `hesabaty-app-*`، `hesabaty-meta` | `hpaint-app-*`، `hpaint-meta` |
| معرّف تطبيق أندرويد | `com.ahmedhassan.hesabaty` | `com.ahmedhassan.hesabatypainting` |
| ملف التحديث | `hesabaty.apk` | `hesabaty-painting.apk` |
| سر التوقيع في GitHub | `HESABATY_KEY_PASSWORD` | `HESABATY_PAINTING_KEY_PASSWORD` |

- التطبيق لا يقرأ أبداً بيانات تطبيق الكهرباء، ويرفض استيراد نسخها الاحتياطية حتى لا تختلط البيانات.
- لو الاتنين اتنشروا على نفس النطاق (`ahmedhassanabdallah.github.io`) بيفضلوا منفصلين: مفاتيح وكاش مختلفين ونطاق Service Worker مختلف.
- تطبيق أندرويد بيتثبت **جنب** تطبيق الكهرباء مش فوقه، وبمفتاح توقيع جديد خاص بيه (مفتاح تطبيق الكهرباء ما اتنسخش هنا).

## الوظائف

- **محرك حسابات النقاشة:** حائط (طول × ارتفاع × أجزاء × أوجه) بخصم الأبواب والشبابيك بسياسات خصم (كامل / بدون / نسبة / مساحة محددة / تجاهل الفتحات الأصغر من حد)، وجوانب الفتحات كبند مستقل، وتقسيم الحائط لأجزاء وحساب أجزاء محددة فقط · غرفة (2 × (الطول + العرض) × الارتفاع + السقف، وكل حائط قابل للتعديل أو الاستبعاد) · سقف بأجزاء · متر مربع · متر طولي · بالقطعة · يومية · مقطوعية.
- **مراحل العمل:** 12 مرحلة قابلة للتعديل، تسعير كل مرحلة بسعرها، وتنبيه عند احتساب نفس المرحلة مرتين على نفس المساحة، وملخص لكل مرحلة.
- **المشاريع:** بالمقاسات أو مقاولة إجمالية، بيانات المشروع ونوع العقار والحالة والتواريخ والشروط.
- **التكاليف والأرباح:** العمال (اليومية × الأيام + الإضافي − السلف − الخصومات)، المصروفات، الخامات على حسابك، صافي الربح النقدي (المحصل − المدفوع فعلاً) منفصل عن المستحقات.
- **النوتة:** العملاء والعربون والدفعات (لمشروع محدد أو توزيع تلقائي) وحساب الخامات، وإيصالات استلام.
- **الخامات:** تصنيفات النقاشة، الشركة والمورد وتاريخ الشراء، وثلاث حالات: على حساب الزبون / الزبون يشتريها / على حسابي ضمن المقاولة.
- **الملاحظات:** ألوان الدهانات وأكوادها ودرجتها، تفاصيل الاتفاق، تعليمات التنفيذ، المواعيد... مربوطة بالمشاريع.
- **قوائم الأسعار:** أكثر من قائمة بعملة لكل قائمة، نسخ واستنساخ الأسعار، وتحديث السعر المرجعي اختيارياً — بدون أسعار إجبارية.
- **المستندات PDF:** مقايسة · عرض سعر · فاتورة أعمال · فاتورة ختامية · إيصال استلام · كشف حساب · تقرير مالي — عربي RTL بخط Cairo، ورقة A4 قابلة للتعديل قبل الطباعة.
- **العملات:** كل العملات العربية بمنازلها العشرية (نفس نظام حساباتي)، وتغيير العملة لا يحوّل المبالغ تلقائياً — التطبيق ينبّه إن القيم محتاجة مراجعة.
- **بدون إنترنت:** تخزين محلي، نسخة احتياطية JSON واستعادة، وService Worker بإصدارات يختار المستخدم بينها.
