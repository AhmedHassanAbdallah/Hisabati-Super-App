# HESABATI PLASTER — حساباتي للمحارة وتشطيبات الواجهات

تطبيق عربي (RTL) يعمل **بدون إنترنت** لحساب وإدارة أعمال:
المحارة الداخلية والخارجية · الجرافيت · الدهارة والمعجون وتجهيز الحوائط · تشطيبات الواجهات · تكاليف الموقع.

مبني على تصميم وفلسفة تطبيق «حساباتي» الأصلي (`AhmedHassanAbdallah/Ezaza`) لكنه **مشروع مستقل تماماً**:
ملفات مستقلة، بيانات مستقلة، ومعرّف أندرويد مستقل. لم يتم تعديل أي ملف في مستودع حساباتي الأصلي.

## المميزات

- **حصر المساحات**: غرف، حوائط وأشكال غير منتظمة، واجهات بالأدوار، أطوال (كرانيش)، خصم فتحات بقواعد قابلة للتخصيص، أكتاف وجوانب، متر/سنتيمتر.
- **حاسبات الخامات**: محارة أسمنتية (نسبة حجمية أو كجم/م³)، محارة جاهزة وجبسية، معجون ودهارة وبرايمر ودهانات وعزل بمعدلات المنتج، جرافيت + برايمر، شبك، خامات تكميلية.
- **الواجهات**: تقسيم المشروع لمناطق (رئيسية، خلفية، جانبية، سور، بلكونات، أعمدة، كرانيش)، لكل منطقة لون ونظام تشطيب وأسعار مختلفة، وأنظمة تشطيب جاهزة.
- **طرق المحاسبة**: م² · م.ط · م³ · يومية · قطعة · مقطوعية — مصنعية فقط / توريد / توريد وتنفيذ / تصنيع وتنفيذ — مقاولة كاملة — حسب المراحل.
- **المشروعات**: عملاء، 8 مراحل، دفعات، مصروفات (سقالات، نقل، ونش...)، يوميات العمال، نسبة التنفيذ، الربح الفعلي والتقديري، الرصيد النقدي.
- **المخزن**: خامات بمعدلات تغطية وأسعار، شراء وبيع وصرف للمشروعات وهالك وتسوية، تنبيه الحد الأدنى، قيمة المخزون وربح المبيعات.
- **المستندات** (طباعة / PDF / واتساب): مقايسة (عامة، محارة، جرافيت، دهارة، واجهات)، عرض سعر، فاتورة مصنعية، فاتورة توريد، فاتورة توريد وتنفيذ، مستخلص، إيصال استلام، كشف حساب عميل، تقرير تكلفة، كشف خامات، تقرير أرباح.
- **العملات العربية** (رمز فقط بدون أسعار صرف ثابتة)، وضع ليلي، نسخ احتياطي واستعادة.

كل الافتراضات والمعادلات موضحة في [docs/ASSUMPTIONS.md](docs/ASSUMPTIONS.md).

## هيكل المشروع

```
index.html          الواجهة
css/app.css         التصميم (نفس هوية حساباتي)
js/engine.js        محرك الحسابات — مستقل عن الواجهة (يعمل في Node للاختبارات)
js/catalog.js       أنواع الأعمال، المراحل، العملات، القيم الاسترشادية
js/store.js         التخزين المحلي (مفاتيح hplaster_ فقط) والنسخ الاحتياطي
js/ui.js            أدوات الواجهة والتنقل
js/editors.js       محرر القياس والخامات (البند والمنطقة)
js/views.js         الرئيسية، المشروعات، المشروع، الحاسبات
js/admin.js         العملاء، العمال، المخزن، التقارير، الإعدادات
js/docs.js          المستندات والطباعة والواتساب
service-worker.js   العمل بدون إنترنت (كاش hplaster- فقط)
android/            تطبيق أندرويد (com.ahmedhassan.hesabaty.plaster)
tests/              اختبارات المحرك + اختبار تشغيل كامل في المتصفح
```

## عزل البيانات عن تطبيقات حساباتي الأخرى

كل تطبيقات حساباتي على GitHub Pages بتشتغل على نفس النطاق `ahmedhassanabdallah.github.io`، لذلك:
- كل مفاتيح التخزين تبدأ بـ `hplaster_` (تطبيق الكهرباء يستخدم `hesabaty_...` و`ahmed_elec_...`).
- كل أسماء الكاش تبدأ بـ `hplaster-` والتنظيف لا يلمس غيرها.
- «مسح كل البيانات» يمسح مفاتيح `hplaster_` فقط.
- الاختبار `tests/e2e.js` بيتأكد من النقط دي تلقائياً.

## الاختبارات

```bash
node --test tests/engine.test.js     # 16 اختبار للمعادلات مقارنة بالحساب اليدوي
npm i --no-save playwright && npx playwright install chromium
node tests/e2e.js                    # تشغيل كامل: مشروع، غرفة، بند، دفعة، حفظ، بدون إنترنت، مستندات، عزل
```

## خطوات النشر (بالعربي وببساطة)

### أولاً: تشغيل التطبيق على الإنترنت (GitHub Pages)
1. افتح المستودع على GitHub: `AhmedHassanAbdallah/Hesabaty-plaster`.
2. اضغط **Settings** (الإعدادات) فوق.
3. من القائمة الجانبية اختار **Pages**.
4. تحت **Branch** اختار الفرع اللي فيه الكود (الفرع الرئيسي بعد الدمج، أو الفرع الحالي للتجربة) والمجلد **/ (root)** ثم **Save**.
5. بعد دقيقة أو اتنين التطبيق هيشتغل على:
   `https://ahmedhassanabdallah.github.io/Hesabaty-plaster/`
6. افتح الرابط من الموبايل ← من قائمة المتصفح اختار **إضافة إلى الشاشة الرئيسية** — وكده يشتغل كتطبيق وبدون إنترنت.

### ثانياً: تطبيق أندرويد (APK)
- كل مرة يتم رفع تعديل، GitHub بيبني ملف APK تلقائياً:
  **Actions ← Android APK ← آخر تشغيل ← Artifacts ← hesabati-plaster-apk**.
- ده APK للتجربة. علشان تعمل نسخة رسمية بتوقيع ثابت (مطلوب للتحديثات وجوجل بلاي):
  1. **Settings ← Secrets and variables ← Actions ← New repository secret**
  2. الاسم: `PLASTER_KEY_PASSWORD` — والقيمة: كلمة سر قوية **احتفظ بيها في مكان آمن**.
  3. بعدها أي رفع على الفرع الرئيسي هيعمل APK موقّع وينشره في **Releases**.

### عند إصدار تحديث
غيّر رقم الإصدار في 3 أماكن بنفس الرقم: `version.json` و `js/app.js` (`APP_VERSION`) و `service-worker.js` (`VERSION`).
