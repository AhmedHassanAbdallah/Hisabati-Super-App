## خطوات النشر
1. **حساب مطوّر**: https://play.google.com/console ← سجّل (رسوم مرة واحدة 25$) وأكّد هويتك.
   ⚠️ الحسابات **الشخصية** الجديدة لازم تعمل **اختبار مغلق (Closed testing) بـ 12 مختبِر لمدة 14 يوم**
   قبل ما جوجل تسمح بالنشر للكل. (حسابات الشركات مش مطلوب منها كده.)
2. **Create app** ← الاسم: `أرزقي | Arzoqi` ← App ← Free ← وافق على الإقرارات.
3. **App content** (محتوى التطبيق) — جاوب كده:
   - Privacy policy: اللينك اللي فوق.
   - Ads: **No** (مفيش إعلانات).
   - App access: **All functionality is available without special access** (تسجيل الدخول بجوجل اختياري).
   - Content rating: املأ الاستبيان — تطبيق أعمال، مفيش عنف أو محتوى للكبار ← هيطلع **Everyone / 3+**.
   - Target audience: **18 وأكبر** (تطبيق أعمال).
   - Data safety (أمان البيانات) — تحت.
   - Government / Financial / Health apps: **No** (أرزقي | Arzoqi برنامج حسابات للصنايعي، مش خدمة مالية أو بنكية).
4. **Store listing**: النصوص والصور اللي فوق.
5. **Testing ← Closed testing** (أو Production لو حسابك شركة) ← Create release ←
   ارفع `hisabati.aab` ← **Use Play App Signing** (افتراضي) ← Save ← Review ← Rollout.

## أمان البيانات (Data safety)
- Does your app collect or share user data? **Yes**
- Is all data encrypted in transit? **Yes**
- Do you provide a way for users to request data deletion? **Yes** (من جوه التطبيق + من درايف)
- البيانات:
  | النوع | Collected | Shared | اختياري؟ | الغرض |
  |---|---|---|---|---|
  | Personal info → **Name**, **Email address** | ✅ | ❌ | Optional | App functionality, Account management |
  | Files and docs → **Files and docs** (النسخ الاحتياطية على درايف المستخدم) | ✅ | ❌ | Optional | App functionality |
  كل البيانات بتروح لحساب جوجل درايف **بتاع المستخدم نفسه** بطلب منه، ومفيش سيرفر للمطوّر.

## بعد أول رفع: ربط التطبيق بالموقع (مهم للتطبيق الحالي TWA)
جوجل بلاي بتعيد توقيع التطبيق بمفتاحها (Play App Signing)، فلازم بصمته تتضاف لملف الربط وإلا هيظهر شريط العنوان فوق:
1. Play Console ← التطبيق ← **Test and release ← App integrity ← App signing**.
2. انسخ **SHA-256 certificate fingerprint** اللي تحت **App signing key certificate**.
3. ابعتها، وهتتضاف لـ `https://ahmedhassanabdallah.github.io/.well-known/assetlinks.json`
   جنب بصمة مفتاح الرفع الموجودة (الاتنين بيفضلوا شغالين).
4. وكمان: Google Cloud ← Google Auth Platform ← Clients ← لو هتستخدم النسخة المستقلة،
   ضيف عميل Android ببصمة SHA-1 بتاعة نفس المفتاح (موضح في `ANDROID-STANDALONE.md`).
