## مهم جداً بعد أول رفع: تسجيل الدخول بجوجل في نسخة بلاي
بلاي بتعيد توقيع التطبيق بمفتاحها (Play App Signing)، فبصمة النسخة اللي بتنزل من بلاي **مختلفة** عن بصمة الـ APK اللي على GitHub.
علشان «تسجيل الدخول بجوجل» والنسخ على درايف يشتغلوا في الاتنين:
1. Play Console ← **Test and release → App integrity → App signing** ← انسخ **SHA-1** اللي تحت **App signing key certificate**.
2. https://console.cloud.google.com ← نفس المشروع ← **Google Auth Platform → Clients → Create client** ←
   Application type: **Android** ← Package name: `com.ahmedhassan.arzaqi` ← SHA-1: البصمة اللي نسختها ← Create.
3. ولو لسه ما عملتهوش: عميل Android تاني بنفس الباكدج وبصمة مفتاح الرفع `F3:67:70:A9:02:F5:A1:CF:2D:A7:86:49:0A:AA:76:38:A6:34:81:1D` (للـ APK اللي على GitHub).
4. **Google Auth Platform → Audience → Publish app** (يكون In production) — وإلا الإيميلات المضافة كـ Test users بس هي اللي تقدر تسجل دخول.
   الصلاحيات كلها غير حساسة (`drive.file`)، فمش محتاجة مراجعة أمنية؛ ممكن جوجل تطلب تأكيد الاسم واللوجو (Brand verification).
